RuneTimer Windows · 민트 테마 / 자동 부스터 안내 / 한눈에 보는 설정 / 새 시작 화면 (2026-10-24)

실행 방법
압축을 풀고 RuneTimer.exe를 실행하세요. 기존 설정은 그대로 유지됩니다.
처음 실행하는 경우 알림 볼륨은 100입니다. 설정에서 볼륨을 조절할 수 있습니다.

시작 화면
앱을 시작하면 승인된 민트 아이콘과 실제 메이플스토리 Bold 글꼴로 그린 짙은 청록색(#176B5B)의 by 꼬맹협회 표시가 있는 작은 시작 화면이 약 2초간 나타나고 메인 화면으로 전환됩니다.

설정 화면
설정을 두 열로 배치하여 기본 저해상도·고해상도 크기에서 모든 항목을 스크롤 없이 확인할 수 있습니다.
현재 PC의 두 화면 모드에서 모든 설정 항목이 표시 영역 안에 들어오는 것을 확인했습니다. 모든 모니터·배율 조합을 검증한 것은 아닙니다.

민트 테마
메인 화면과 위젯의 룬 아이콘은 민트(#4AF1AE), 부스터는 연한 민트(#9FF7D2), 시계는 흰색에 가까운 민트(#E0FCF0)입니다.
메인 카운터 숫자는 실행 중 흰색, 정지 중 회색입니다. 위젯 숫자는 흰색을 유지하며, 메인 카운터와 추가 30분 카운터의 게이지는 흰색 계열 그라데이션, 메인 룬 게이지는 민트색 그라데이션입니다. 위젯에서는 룬 진행 게이지를 표시하지 않으며 룬 숫자와 아이콘은 그대로 유지합니다. 아이콘과 설정 강조색은 민트 계열을 유지합니다.

자동 부스터 안내
설정에서 부스터 모드를 켜세요. 기본값은 꺼짐입니다.
감지된 룬 표시가 사라져 기존 룬 알림이 멈추면 1초 뒤 첫 부스터 사용 안내가 나옵니다.
실제 룬 버프를 확인하는 기능이 아니라 미니맵의 룬 표시가 사라진 것을 기준으로 작동합니다.
설정의 자동 안내 횟수에 원하는 양의 정수를 입력하고 적용하세요. 기본값은 3회이며 첫 안내도 횟수에 포함됩니다.
변경한 횟수는 다음 자동 안내 주기부터 적용됩니다.
100초 주기이며, 다음 사용 안내는 각 주기가 끝나기 3초 전에 나옵니다.
예: 3회 설정 시 첫 안내 이후 97초, 197초에 추가 안내가 나옵니다. 마지막 주기가 끝나면 자동 종료됩니다.
자동 첫 안내는 음성 1회만 재생합니다. 이후 반복 안내는 음성 3회이며 음성 사이에는 0.5초 간격을 둡니다. 부스터 음량은 카운터 알림 볼륨을 따릅니다.
일요일이나 이벤트 여부에 따른 자동 횟수 변경은 없습니다. 필요한 횟수를 직접 설정하세요.
부스터 모드를 끄면 자동 대기와 실행 중인 부스터 타이머가 중단됩니다.
부스터 아이콘을 직접 눌러 시작한 수동 타이머는 기존처럼 다시 누를 때까지 반복합니다.

화면과 위젯
부스터 모드를 켜면 룬 아이콘 옆에 부스터 아이콘이 나타납니다. 끄면 숨겨집니다.
위젯에는 부스터 남은 시간이 표시됩니다. 메인 화면에서 부스터 작동 중에는 초록색 테두리가 표시됩니다.
캡처 확인 창은 설정의 캡처 확인 버튼을 눌렀을 때만 열립니다.

30분 카운터
메인 카운터 사각형 위쪽 우측의 +를 누르면 30분 카운터가 추가됩니다.
30분 카운터를 누르면 시작하고, 종료 10초 전에 음성 3회 안내 후 다음 30분 주기로 반복합니다.
앱을 다시 실행하면 자동 시작하지 않으므로 카운터를 눌러 시작하세요.
30분 카운터 사각형 위쪽 우측의 -를 누르면 삭제되고 원래 크기의 기본 카운터로 돌아갑니다.

배포 구성

RuneTimer-Source.zip: 소스 코드와 테스트
SHA256SUMS.txt: 파일 무결성 확인용 해시

위젯 카운터 상태
카운터가 실행 중이면 일시정지 버튼 II, 일시정지 상태면 실행 버튼 ▶가 표시됩니다. 아이콘 또는 숫자를 누르면 실행과 일시정지가 전환되며 바로 아이콘이 바뀝니다. 드래그는 상태를 바꾸지 않습니다.

카운터 추가·삭제
+ 또는 -를 누르면 0.3초 뒤에 적용됩니다. 대기 중 연속 클릭은 한 번만 처리합니다. 카운터를 눌러 시작·일시정지하는 동작은 즉시 적용됩니다.

메인 카운터 숫자
기본·30분 카운터 모두 실행 중에는 흰색(#FFFFFF), 정지 중에는 회색(#8A9094) 숫자로 표시됩니다.

새 룬 감지 시 부스터 초기화
새로운 룬 등장으로 판정되면 이전 부스터 타이머와 대기·재생 중인 안내를 종료하고 새 룬 기준으로 다시 준비합니다. 이후 그 룬 표시가 사라지면 기존처럼 1초 뒤 첫 부스터 안내를 시작합니다. 계속 표시되는 같은 룬은 매 프레임 초기화하지 않습니다.

버튼 위치
+와 - 버튼은 카운터 사각형 바깥 위쪽 우측에 표시됩니다. 클릭 후 0.3초 지연 동작은 유지됩니다.


미니맵 캡처 영역 지정
캡처 아이콘을 누른 뒤 첨부 예시 이미지의 범위처럼 드래그하세요.
지도 제목과 미니맵의 흰 테두리 네 면을 모두 포함하세요. 테두리 바깥 여백은 예시처럼 조금만 남기고, 주변 게임 화면까지 과하게 넓히지 마세요.
설정 → 캡처 확인 / 소리 테스트에서 제목과 미니맵 테두리가 잘리지 않았는지 확인하세요.
첨부된 minimap-region-wide.png 이미지 전체가 캡처할 범위의 예시입니다. 이미지 바깥으로 추가 여백을 크게 잡을 필요는 없습니다. 이 이미지는 범위를 설명하는 모형 화면입니다.
캡처 후에도 룬이 감지되지 않거나 알림음이 나오지 않으면, 설정 → 캡처 확인 / 소리 테스트를 누른 뒤 열린 창에서 다시 찾기를 눌러주세요.
