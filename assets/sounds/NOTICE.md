# TTS 알림 음원 — 생성 경위 및 사용 조건 기록

## 파일

| 파일 | 용도 |
|---|---|
| `tts_rune.mp3` | 룬 감지 알림 |
| `tts_rune_due.mp3` | 수동 모드 룬 등장 예정 알림 |
| `tts_warning.mp3` | 경고 알림 |
| `tts_booster.mp3` | 부스터 100초 주기의 97초 알림 · 사용자가 2026-10-24 제공한 `ttsmaker-file-2026-10-24-15-17-53.mp3` 원본 |
| `tts_halfhour.mp3` | 30분 카운터 종료 10초 전 알림 · 사용자가 제공한 `ttsmaker-file-2026-10-24-15-39-3.mp3` 원본 |

## 생성 경위

- 생성 도구: [TTSMaker](https://ttsmaker.com/) — 온라인 TTS 서비스
- 직접 녹음한 음성이 아니라 TTS 서비스로 합성한 결과물입니다.
- 인코딩: LAME 3.100 (파일 메타데이터 기준)

## 사용 형태

`rune_timer.spec`의 datas로 `assets/sounds` 전체가 exe에 포함되어 재배포됩니다.
즉 TTS 생성물이 **다운로드 배포되는 애플리케이션에 포함된 상태로 제3자에게
전달**됩니다.

## 라이선스 성격

TTS 생성물의 사용 권리는 이 저장소의 GPL-3.0-or-later가 아니라 TTSMaker의
이용약관을 따릅니다. TTSMaker는 음성(voice)별로 사용 조건을 별도로 표기하므로,
"TTSMaker로 만들었다"는 사실만으로는 조건이 결정되지 않습니다.

## 확인 이력

배포 전에 아래 표를 채우세요.

| 확인일 | 사용한 음성(voice) | 확인한 URL | 재배포 가능 여부 | 요구되는 출처 표기 |
|---|---|---|---|---|
| (미확인) | (미기록) | https://ttsmaker.com/copyright | 확인 필요 | 확인 필요 |

확인해야 할 항목:

- 사용한 음성이 상업적 이용을 허용하는지
- 생성 음원을 배포용 소프트웨어에 **포함해 재배포**하는 것이 허용되는지
  (단순 콘텐츠 사용과 소프트웨어 번들 재배포는 조건이 다를 수 있음)
- 출처 표기(attribution)가 요구되는지, 요구된다면 정확한 문구와 표기 위치
- 조건이 맞지 않을 경우의 대안: 조건이 명확한 음성으로 재생성, 직접 녹음,
  또는 Windows 내장 SAPI TTS 런타임 합성으로 전환

## 참고

어떤 음성을 썼는지 기록이 남아 있지 않다면, 조건이 명확한 음성으로 다시 생성해
이력을 남기는 편이 안전합니다.
