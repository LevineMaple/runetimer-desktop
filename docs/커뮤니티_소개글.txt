[공유] 룬 등장·부스터 사용 타이밍을 알려주는 룬 타이머

안녕하세요, 르빈입니다.
사냥하다 보면 룬이 뜬 걸 놓치거나, 부스터를 다시 써야 할 때 깜빡하는 경우가 있어 룬 타이머를 준비했습니다.
미니맵을 보고 룬 등장을 소리로 알려주고, 카운터와 부스터 사용 안내를 함께 볼 수 있는 Windows용 프로그램입니다.

■ 룬 등장 알림
지정한 미니맵 영역에서 룬 표시를 감지하면 알림음을 들려줍니다.
메인 화면과 작은 위젯 화면을 지원해서 원하는 크기로 띄워둘 수 있습니다.

[사진: high-two-counters.png — 최신 메인 화면, 30분 카운터 추가 상태]

■ 부스터 사용 안내
설정에서 부스터 모드를 켜면 사용할 수 있습니다.
룬 표시가 사라진 뒤 1초 후에 첫 부스터 사용 안내가 음성 1회 나옵니다.
그다음부터는 100초 주기로 돌아가며, 종료 3초 전에 음성 3회로 알려줍니다. 음성 사이 간격은 0.5초입니다.
설정의 ‘부스터 사용 횟수’에는 첫 안내를 포함한 사용 횟수를 입력하면 됩니다.
예를 들어 3회로 설정하면 첫 안내, 97초 뒤, 197초 뒤에 안내가 나옵니다.
이벤트 등으로 더 오래 사용할 때는 원하는 횟수로 바꿀 수 있습니다.
실제 룬 버프나 아이템 사용을 확인하는 방식은 아니며, 미니맵에서 룬 표시가 사라진 시점을 기준으로 안내합니다.

[사진: high-widget-running.png — 최신 위젯 화면]

■ 기본 카운터와 30분 카운터
기본 카운터의 간격을 설정할 수 있고, 카운터 위의 +를 누르면 30분 카운터를 추가할 수 있습니다.
30분 카운터는 직접 눌러 시작하며, 종료 10초 전에 음성 3회로 알려준 뒤 다시 30분을 셉니다.
필요 없을 때는 위쪽 - 버튼으로 지울 수 있습니다. 앱을 다시 실행하면 카운터를 눌러 시작해 주세요.


■ 설정과 위젯
룬 알림과 카운터 알림의 볼륨을 따로 조절할 수 있고, 부스터 음량은 카운터 볼륨을 따릅니다.
캡처 없이 타이머를 쓰는 수동 모드도 있습니다.
위젯에서는 룬·부스터·카운터를 한눈에 볼 수 있으며, 카운터 숫자나 재생·일시정지 아이콘을 누르면 상태가 전환됩니다.

[사진: high-settings.png — 최신 설정 화면]

■ 처음 실행할 때
1. 릴리즈에서 RunTimer-Windows.zip을 내려받아 압축을 풀고 RuneTimer.exe를 실행해 주세요.
2. 캡처 아이콘을 눌러 아래 예시처럼 지도 제목과 미니맵의 흰 테두리 전체를 포함해 주세요. 바깥 여백은 조금만 남기면 됩니다.
3. 캡처했는데도 룬이 감지되지 않거나 알림음이 나오지 않으면, 설정 → 캡처 확인 / 소리 테스트 → 다시 찾기를 눌러주세요.
4. 부스터 안내가 필요하면 설정에서 부스터 모드를 켜고 사용 횟수를 정해 주세요.
